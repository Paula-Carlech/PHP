# PHP Exercises

A collection of PHP exercises created to improve problem-solving, coding fluency, and backend development skills.

The goal of this repository is not to learn PHP syntax from scratch, but to practice writing code and to strengthen programming fundamentals through consistent hands-on exercises.

---

## Repository Structure

```text
php-exercises/
├── beginner/
├── intermediate/
├── advanced/
└── notes/
```

### Beginner

Exercises focused on:

- Arrays
- Loops
- Functions
- Conditional statements
- State manipulation
- Basic business rules

---

### Intermediate

Exercises focused on:

- Data relationships
- Object-oriented programming
- Validation rules
- More complex business logic
- Multiple entities working together

Examples:

- Student management
- Library system
- Bank account operations
- Task management

---

### Advanced

Exercises focused on:

- Application architecture
- Authentication
- APIs
- Persistence
- Design patterns
- Real-world backend scenarios

Examples:

- Authentication system
- Blog API
- Inventory API
- Order cancellation flow

---
